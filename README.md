# Projeto Países

Aplicação desktop em C# com Windows Forms para gerenciar países, estados, cidades, cargos e funcionários.

## Funcionalidades

- Cadastro, consulta, alteração e exclusão de registros.
- Relacionamento entre países, estados e cidades.
- Cadastro de funcionários com informações pessoais, cargo e cidade.
- Armazenamento dos dados em banco SQL Server LocalDB.

## Tecnologias

- C# e Windows Forms
- .NET Framework 4.8
- SQL Server LocalDB
- ADO.NET

O código está organizado nas pastas Model, View, Controller e DAO.

## Como executar

1. Instale o Visual Studio com a carga de trabalho **Desenvolvimento para desktop com .NET** e o suporte ao **.NET Framework 4.8**.
2. Instale o **SQL Server Express LocalDB 2025**, versão utilizada para preparar e testar o banco incluído.
3. Clone ou baixe este repositório e extraia os arquivos, se necessário.
4. Abra o arquivo `Grafico_2026_Rafael_Dias.csproj` no Visual Studio.
5. Pressione **F5** para compilar e executar.

Os arquivos `.mdf` e `.ldf` do banco já acompanham o projeto e devem permanecer na pasta do projeto. Não é necessário executar os scripts SQL para começar.
